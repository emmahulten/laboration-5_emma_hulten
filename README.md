# Laboration 5 - Studentkortsgenerator

🌱 Beskrivning
En webbapplikation där användaren kan skapa studentkort genom att ange namn, e-postadress och telefonnummer samt välja typsnitt.

Applikationen innehåller:
- Formulärvalidering med felmeddelanden.
- Generering av studentkort med valbart typsnitt.
- Historik över skapade studentkort.
- Lagring av historik med localStorage.
- Möjlighet att rensa formuläret och radera historiken.

🛠 Tekniker
- HTML
- CSS
- JavaScript
- Web Storage(localStorage)
